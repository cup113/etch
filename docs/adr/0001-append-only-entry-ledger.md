# ADR-0001: 追加式刻痕账本（append-only entry ledger）

计分器一定会遇到刻错，而产品隐喻是"刻上去即永恒"。我们决定：**笔（Entry）不可改、不可删**，改错的唯一方式是再刻一笔**凿除（Chisel）**指向它；当前分永远是对全部未被凿除的笔做**折叠（Fold）**的结果。这是唯一让隐喻成为存储格式本身的方案（append-only 事件日志），完整历史审计随之免费；代价是"改错"比直接编辑多一步，由 UI 的一键凿除兜底。

## Considered Options

- 可编辑但留痕（soft delete + 修订记录）——更顺手，但"石头能被悄悄磨掉"，且要维护双向状态。
- 限时撤回窗口（5 分钟内可 undo，之后固化）——引入"水泥半干"状态，与"刻了就永恒"直接矛盾。

## Consequences

- 存储层天然是 append-only 事件日志，多笔原子刻入（模板一局摊出全桌的行）天然在一个事务里。
- 将来若做多设备同步（ADR-0002 的遗留项），账本结构可直接对接 CRDT/操作变换，无需迁移。
- 凿除不可被再凿除：冲正的冲正 = 重新刻原内容的一笔。
